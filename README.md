# GERMiFY

Мини-соцсеть на Django: лента постов, лайки, комментарии и ответы, личные сообщения, профили и подписки, сообщества с участниками/админами. Фронт — Django templates + ванильный JS + CSS.
(находится на этапе минимально жизнеспособного проекта, будет проходить чистка директории, нормализация логики и данных) 
## Возможности

- Лента постов (пагинация/подгрузка, создание/удаление)
- Вложения к постам (файлы/картинки) + хранение в `media/`
- Лайки на посты и комментарии
- Комментарии и ответы (replies)
- Личные сообщения (inbox + polling)
- Профили пользователей (аватар, bio)
- Подписки (follow/unfollow)
- Сообщества: создание, вступление/выход, участники, админы, посты внутри сообщества

## Технологии

- Python / Django (проект: `germify`, приложение: `core`)
- База данных: **MySQL** (по умолчанию в `settings.py`)
- Статика: `core/static/` → сборка в `staticfiles/`
- Медиа: `media/` (аватары, вложения, иконки сообществ)

## Структура проекта

- `backend/manage.py` — entrypoint Django
- `backend/germify/` — настройки/URL/WSGI проекта
- `backend/core/` — основное приложение (models, views, templates, static)
- `backend/media/` — пользовательские загрузки (не коммитится)
- `backend/staticfiles/` — результат `collectstatic` (для продакшена)
